# Scheduling Optimizer

A web app that builds clash-free college timetables. It works for any college: the college enters its own days, periods, rooms, teachers, sections and subjects, and the app generates a timetable with no teacher, room or section clashes.

Built for Hackathon 1 — Punjab Jobs AI Bootcamp (J-PAL South Asia).

## Status

Work in progress. Planned features:

- Load a sample college with one click
- Enter data through forms or CSV import (templates provided)
- Check input data for impossible cases before generating
- Generate a timetable with no clashes, verified by an independent checker
- View timetables by section, teacher and room; print them
- Quality score (balanced load, few gaps, subjects spread across the week)

## Setup

No installation needed. Open `index.html` in a browser, or serve the folder with any static host.
